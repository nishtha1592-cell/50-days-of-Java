# 50-days-of-Java
Committing daily to upgrade my Java attributes from absolute beginner to production-ready developer.

Welcome to my Java learning repository! This project documents my 50-day intensive journey to mastering Java, moving systematically from core runtime fundamentals to advanced object-oriented design, the Collections Framework, Generics, and Functional Streams.

---

## 🎯 Core Objectives
- **Deep Execution Knowledge:** Understand how Java manages memory (Stack vs. Heap, String Pool, and reference mechanics).
- **Rock-Solid OOP Foundation:** Master polymorphism, custom immutability, nested structures, and decoupling via interfaces.
- **Modern Java Mastery:** Leverage the Power of Generics, the Collections Framework, Lambda expressions, and Streams.

---

**Day 01:** JVM, JDK, JRE architecture; Variables & Data Types;Storage of negative numbers & Floating-point numbers.
**Day 02:**	Type conversion & Type promotion; Automatic vs. Manual Type Casting; Java Operators (Arithmetic, Unary, and Assignment).  
**Day 03:**	Decision-making structures: if, else-if ladders, and switch statements.  
**Day 04:**	Control Flow loops (for, while) and jump statements (break, continue keywords).  
**Day 05:**	Internal mechanics of Arrays in Java: Heap allocation, reference passing, and contiguous storage layout.  
**Day 06:**	Basic functions in Java; Method Overloading rules; Recursion principles and call stack mechanics.  
**Day 07:** Day 07	Introduction to Object-Oriented Programming (OOP) principles in Java.  	
**Day 08:**	Constructors, Type of constructors (Default vs. Parameterized), and the deep mechanics of the this keyword.    
**Day 09:**	Memory parameters: Call by Value vs. Call by Reference myth in Java; Object references on the stack.  
**Day 10:**	Encapsulation principles (Data hiding) and Inheritance (Code reuse mechanics) in Java.  	
**Day 11:** Abstraction and Polymorphism in depth (Compile-time vs. Runtime binding / Method Overriding).  	
**Day 12:**	Autoboxing and Unboxing; Abstract Classes; Creating POJOs (Plain Old Java Objects).  
**Day 13:**	Java Nested Classes: Static nested classes, Inner classes, Local classes, and Anonymous classes.  
**Day 14:**	Immutable Classes in Java: Designing custom immutable objects from scratch step-by-step.  
**Day 15:**	The Parent of all classes: Deep dive into the java.lang.Object class and its foundational methods (equals(), hashCode(), toString()).  	
**Day 16:**	Java Enums: Type-safe enumerations, custom fields, methods, and enum constants.  
**Day 17:** Java Interfaces deep dive: Multiple inheritance workarounds, default methods, and static methods.    
**Day 18:**	Java Strings Part 1: String Immutability, Memory footprints, and the String Constant Pool internal workings.    	
**Day 19:**	Java Strings Part 2: Essential String methods; StringBuilder vs. StringBuffer (Thread safety vs. Performance evaluation).    	
**Day 20:**	Generics in Java: Type-safety constraints, Generic classes, and Generic methods.
